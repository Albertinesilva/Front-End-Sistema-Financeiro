# 💰 Financial System Frontend (Angular)

Aplicação frontend desenvolvida com Angular para um sistema financeiro, focada na construção de interfaces modernas, componentização e consumo de APIs REST.

---

## 🚀 Objetivo

Este projeto tem como objetivo demonstrar a construção de uma aplicação frontend para gerenciamento de dados financeiros, aplicando boas práticas de desenvolvimento com Angular.

---

## 🛠️ Tecnologias utilizadas

- Angular
- TypeScript
- HTML & CSS
- RxJS
- REST API

---

## ⚙️ Funcionalidades

- 📊 Visualização de dados financeiros
- ➕ Cadastro de registros
- ✏️ Edição de informações
- ❌ Exclusão de dados
- 🔄 Integração com API backend

---

## 🧠 Conceitos aplicados

- Componentização
- Data Binding
- Injeção de dependência
- Consumo de APIs REST
- Arquitetura baseada em serviços
- Organização modular

---

## 📂 Estrutura do projeto

O projeto segue a estrutura padrão Angular:

- `components/` → componentes da interface
- `services/` → comunicação com API
- `models/` → estruturas de dados
- `pages/` → telas da aplicação

---

## ▶️ Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/Albertinesilva/front-end-sistema-financeiro
```

2. Acesse a pasta do projeto:

```bach
cd front-end-sistema-financeiro
```

3. Instale as dependências:

```bach
npm install
```

4. Execute o projeto:

```bach
ng serve
```

5. Acesse no navegador:

```bach
http://localhost:4200
```
